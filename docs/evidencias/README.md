# Evidências de execução

Esta pasta receberá as capturas e gravações reais do aplicativo em aparelho ou emulador. Nenhuma imagem de execução foi fabricada.

A compilação e os testes locais já executados estão descritos em [VALIDACAO.md](../VALIDACAO.md). Eles não substituem a gravação do aplicativo sendo fechado e reaberto.

Com um dispositivo disponível, seguir [ROTEIRO_DE_EVIDENCIAS.md](../ROTEIRO_DE_EVIDENCIAS.md) ou executar o script `scripts/testar-persistencia.ps1` para os testes automatizados e as capturas. Gravar também um vídeo sem cortes do teste de encerramento e reabertura.
